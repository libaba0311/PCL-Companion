# 给 PCL 作者的项目介绍

你好，我最近做了一个名为 **PCL Companion** 的免费开源小工具，希望在公开发布前先向你说明它与 PCL 的关系和边界，也欢迎你指出任何不合适之处。

## 为什么做这个项目

PCL 仍然是一款很优秀的 Minecraft 启动器。这个项目无意重新实现另一个 PCL，也不负责账号、启动参数、游戏启动或崩溃分析。它只想承担一个更窄的角色：浏览社区资源，把用户选择的原版或整合包准备成标准实例目录，然后交还给 PCL 使用。

简单来说：**PCL 负责启动与管理，PCL Companion 负责下载与部署。**

## 目前能做什么

- 检测用户本地的 PCL 与 `.minecraft`；
- 浏览 Modrinth 的 Mod、整合包、数据包、资源包和光影包；
- 按 Minecraft 版本、加载器和类别筛选，并分页展示；
- 下载原始发布文件并验证哈希；
- 读取 Mojang 官方版本清单；
- 将 Fabric 与 Forge `.mrpack` 在临时目录中构建后部署成独立实例；
- 安装完成后提示用户回到 PCL 手动刷新版本列表；
- 允许用户明确选择 PCL 当前目录或自定义 `.minecraft`。

## 与 PCL 的明确界限

PCL Companion 是独立进程和独立代码库：

- 不修改、注入、替换或重新分发 PCL 可执行文件；
- 不读取 PCL 的账号、令牌或登录数据；
- 不调用 PCL 的私有接口，不模拟 PCL UI 操作；
- 不复制 PCL 源码、图片、图标或内部下载实现；
- 不修改 PCL 的版本缓存，部署完成后只提示用户手动刷新；
- “PCL”只用于说明兼容对象，不表示官方、合作或认可关系。

项目界面与安装逻辑均为独立实现。所有第三方资源仍来自 Mojang、Modrinth、Fabric、Forge 等上游，本项目不建立付费资源镜像，也不绕过访问控制。

## 开源与收费

项目源代码采用 MIT License 发布，当前软件免费提供、无广告、无遥测、无后端账号系统，也没有收费计划。运行时配置和任务数据只保存在用户本机。

## 仍在完善的地方

- 原版 Libraries 与 Assets 的完整预下载；
- NeoForge/Quilt 更多版本的验证；
- 更完善的断点续传、镜像切换和错误恢复；
- 打包成不依赖本机 Python 的正式 Windows 版本。

如果项目名称、界限说明、交互方式或兼容策略有可能造成误解，我愿意调整。也希望这个小工具能在不打扰 PCL 本身开发节奏的前提下，为有需要的用户补充一个独立、透明、可审计的下载入口。

感谢你长期维护 PCL。
